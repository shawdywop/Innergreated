# INNERGREATED Website

Static artist website ready for GitHub Pages or another static host.

## Files

- `index.html` — page content and structure
- `styles.css` — visual design and responsive layout
- `script.js` — navigation and signup preview behavior
- `assets/inner-sun.jpg` — hero artwork

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload every file and the `assets` folder to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will show the website address after deployment completes.

## Important

The email signup is currently a visual preview. It does not store email addresses until an email-list provider is connected.
